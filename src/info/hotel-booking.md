Большая задача по Binding — бронирование отеля

Сделай одностраничное приложение Hotel Booking, в котором пользователь может выбрать номер и настроить бронирование.

Никакого backend — все данные хранятся в компоненте.

Исходные данные

Есть список номеров. Каждый номер содержит:

{
id: number;
name: string;
description: string;
price: number;
capacity: number;
image: string;
available: boolean;
rating: number;
}

Создай минимум 6 номеров с разными ценами, вместимостью, рейтингом и доступностью.

Требования
В верхней части страницы должен отображаться заголовок отеля и количество доступных номеров.
Добавь поле поиска. При вводе текста список номеров должен сразу фильтроваться по названию.
Добавь выбор количества гостей: от 1 до 6.
После выбора количества гостей показывай только номера, которые подходят для указанного количества человек.
Добавь фильтр:
All
Available
Unavailable

При выборе фильтра соответствующая кнопка должна визуально становиться активной.

Добавь максимальную стоимость номера за ночь. Пользователь вводит сумму, после чего более дорогие номера исчезают из списка.
Все фильтры должны работать одновременно.

Например:

Search: deluxe
Guests: 2
Status: Available
Max price: 150

Номер должен отображаться только тогда, когда удовлетворяет всем четырём условиям.

Для каждого номера выведи:
изображение;
название;
описание;
цену за ночь;
вместимость;
рейтинг;
статус.
Недоступные номера должны визуально отличаться от доступных.
Кнопка Book now должна быть доступна только для свободных номеров.
При нажатии Book now номер становится выбранным.

Одновременно может быть выбран только один номер.

Выбранная карточка номера должна визуально отличаться от остальных.
После выбора номера под списком должна появиться секция Booking details.
В Booking details покажи название выбранного номера и его стоимость за ночь.
Добавь выбор количества ночей.

Минимум:

1

Максимум:

30
При изменении количества ночей итоговая стоимость должна пересчитываться автоматически.

Например:

Room: €120
Nights: 4

Total: €480
Добавь дополнительную услугу:
Breakfast — €15 per guest / night

Пользователь должен иметь возможность включить или отключить её через checkbox.

Если завтрак выбран, итоговая стоимость должна учитывать:

количество гостей
×
количество ночей
×
15
Добавь ещё одну дополнительную услугу:
Airport transfer — €40

Это разовая стоимость, независимо от количества гостей и ночей.

Покажи разбивку стоимости:
Room: €480
Breakfast: €120
Airport transfer: €40

Total: €640

Не показывай строку дополнительной услуги, если пользователь её не выбрал.

Добавь поле:
Guest name

Под ним в реальном времени отображай:

Booking for: John Smith

Если поле пустое, этот текст показываться не должен.

Добавь textarea:
Special requests

И рядом счётчик:

34 / 200

Максимальная длина текста — 200 символов.

Когда осталось меньше 20 символов, счётчик должен визуально измениться.

Добавь кнопку:
Confirm booking

Она должна быть недоступна, если:

номер не выбран;
имя гостя пустое;
количество ночей некорректно.
После Confirm booking вместо формы покажи информацию об успешном бронировании:
Booking confirmed!

Guest: John Smith
Room: Deluxe Room
Guests: 2
Nights: 4
Total: €640
Добавь кнопку:
New booking

Она должна полностью сбрасывать состояние приложения и возвращать пользователя к первоначальному экрану.

Если после применения фильтров ни одного номера не найдено, вместо пустого списка покажи:
No rooms match your filters.
Дополнительное усложнение: добавь сортировку:
Default
Price: Low to High
Price: High to Low
Rating

Она должна работать вместе со всеми существующими фильтрами.

Дополнительное усложнение: возле каждого номера сделай кнопку ♡, позволяющую добавить номер в избранное. После добавления она должна превращаться в ♥.

Вверху страницы показывай:

Favorites: 3

Избранное не должно сбрасываться при изменении фильтров.

В этой задаче постарайся использовать именно то, что мы уже проходили по One-Way и Two-Way Binding. Не добавляй пока Reactive Forms, сервисы, RxJS или API — здесь задача именно на понимание binding.
