## Фильтр статуса

Добавь три кнопки:

```text
All
Available
Unavailable
```

Активная кнопка должна визуально отличаться.

Фильтр должен менять отображаемые номера.

## Максимальная цена

Добавь поле:

```text
Max price per night
```

Пользователь вводит максимальную стоимость номера.

Более дорогие номера должны исчезать.

Например:

```text
Max price: 150
```

Номер стоимостью `€180` не показывается.

## Совместная работа фильтров

Все фильтры должны работать одновременно.

Например:

Guests: 2
Status: Available
Max price: 150

````

Номер показывается только тогда,
когда подходит под все условия.

## Карточка номера

Для каждого номера покажи:

- изображение;
- название;
- описание;
- цену за ночь;
- вместимость;
- рейтинг;
- статус;
- кнопку `Book now`;
- кнопку избранного `♡`.

Недоступные номера должны визуально отличаться.

Например, можно уменьшить прозрачность карточки
или изменить её фон.

Статус такого номера:

```text
Unavailable
````

## Book now

Добавь кнопку:

```text
Book now
```

Она должна быть доступна только для свободных номеров.

После нажатия номер становится выбранным.

Одновременно может быть выбран только один номер.

Выбранная карточка должна визуально отличаться от остальных.

Например, можно добавить класс:

```text
selected
```

и показать рамку вокруг карточки.

## Booking details

После выбора номера покажи секцию:

```text
Booking details
```

В ней выведи:

```text
Room: Deluxe Room
Price per night: €120
```

## Количество ночей

Добавь поле:

```text
Nights
```

Допустимое количество ночей:

```text
1–30
```

При изменении количества ночей
стоимость должна пересчитываться автоматически.

Например:

```text
Room: €120
Nights: 4

Total: €480
```

## Breakfast

Добавь checkbox:

```text
Breakfast
€15 per guest / night
```

Стоимость завтрака рассчитывается так:

```text
guests × nights × 15
```

Например:

```text
Guests: 2
Nights: 4

Breakfast:
2 × 4 × €15 = €120
```

Пользователь должен иметь возможность
включить или отключить завтрак.

## Airport transfer

Добавь ещё один checkbox:

```text
Airport transfer
€40
```

Это разовая стоимость.

Она не зависит от количества гостей
или количества ночей.

## Разбивка стоимости

Покажи подробную стоимость бронирования:

```text
Room: €480
Breakfast: €120
Airport transfer: €40

Total: €640
```

Если дополнительная услуга не выбрана,
её строку показывать не нужно.

Например, без завтрака:

```text
Room: €480
Airport transfer: €40

Total: €520
```

## Guest name

Добавь поле:

```text
Guest name
```

При вводе имени сразу показывай:

```text
Booking for: John Smith
```

Если поле пустое,
этот текст показываться не должен.

## Special requests

Добавь `textarea`:

```text
Special requests
```

Максимальная длина текста:

```text
200
```

Рядом показывай количество введённых символов:

```text
34 / 200
```

Когда до лимита осталось меньше 20 символов,
счётчик должен визуально измениться.

Например:

```text
184 / 200
```

можно выделить другим цветом.

## Confirm booking

Добавь кнопку:

```text
Confirm booking
```

Она должна быть отключена, если:

- номер не выбран;
- имя гостя пустое;
- количество ночей меньше 1;
- количество ночей больше 30.

## Успешное бронирование

После нажатия `Confirm booking`
спрячь форму бронирования.

Вместо неё покажи:

```text
Booking confirmed!

Guest: John Smith
Room: Deluxe Room
Guests: 2
Nights: 4
Total: €640
```

## New booking

После успешного бронирования добавь кнопку:

```text
New booking
```

Она должна полностью сбрасывать
состояние приложения.

После сброса пользователь должен вернуться
к первоначальному экрану.

## Пустой результат

Если после применения фильтров
ни одного номера не найдено, покажи:

```text
No rooms match your filters.
```

Не оставляй просто пустое место.

## Сортировка

Добавь сортировку:

```text
Default
Price: Low to High
Price: High to Low
Rating
```

Сортировка должна работать одновременно
со всеми существующими фильтрами.

Например:

```text
Search: room
Guests: 2
Status: Available
Max price: 200
Sort: Price: Low to High
```

Сначала должны примениться все фильтры,
а затем подходящие номера сортируются по цене.

## Favorites

Возле каждого номера добавь кнопку:

```text
♡
```

При нажатии номер добавляется в избранное.

После добавления кнопка должна выглядеть так:

```text
♥
```

Повторное нажатие должно удалить номер
из избранного.

В верхней части страницы показывай:

```text
Favorites: 3
```

Количество должно обновляться автоматически.

Избранное не должно сбрасываться
при поиске, фильтрации или сортировке.

## Что нужно потренировать

В этой задаче постарайся использовать:

- Interpolation;
- Property Binding;
- Event Binding;
- Two-Way Binding;
- `[class]`;
- `[disabled]`;
- `[value]`;
- `(click)`;
- `(input)`;
- `[(ngModel)]`.

Самостоятельно решай, какой тип binding
лучше подходит для каждой части приложения.

## Ограничения

Пока не используй:

- Reactive Forms;
- сервисы;
- RxJS;
- API;
- backend.

Все данные и состояние приложения
должны находиться внутри компонента.

Главная цель задачи —
потренировать One-Way и Two-Way Binding.
